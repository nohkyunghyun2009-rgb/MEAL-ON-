# MEAL:ON 앱 안에서 결제하기 (토스페이먼츠)

예약금(1명당 **2,000원**)을 앱 안에서 **토스페이먼츠 결제창**으로 결제해요.
지금은 **테스트 키**가 들어있어서 결제창은 진짜처럼 뜨지만 **돈은 안 빠져나가요.** 발표·시연용으로 그대로 쓰면 돼요.

---

## 1. 켜는 법 (터미널 2개)

**터미널 1 — 결제 승인 서버** (Node.js 18 이상 필요, https://nodejs.org)

```bash
cd server
npm start
```
→ `MEAL:ON 결제 승인 서버 켜짐 → http://localhost:3000` 이라고 나오면 성공.

**터미널 2 — 앱** (원래 하던 대로)

```bash
flutter run -d chrome --web-port 8080
```
(VS Code에서는 F5)

## 2. 시연 순서

홈 → 식당 예약 → 식당 → 메뉴 → 예약 정보 입력 → **결제하기** → 확인창 →
**토스 결제창** (카드 선택) → 결제 → 앱으로 돌아옴 → "결제 확인 중…" → **예약 완료 화면**

테스트 결제창에서 카드 정보는 **아무 숫자**나 넣어도 돼요 (카드번호 16자리, 유효기간, 생년월일 등).
완료 화면에 "결제 수단: 카드" 와 "결제 키" 가 보이면 진짜 승인까지 된 거예요.

> 결제창에서 X 를 누르면 "결제를 취소했어요" 하고 입력 화면에 그대로 남아요.
> 승인 서버를 안 켰으면 "결제 승인 서버에 연결할 수 없어요" 화면이 나와요 → 터미널 1 확인.

---

## 3. 어떻게 돌아가나요? (구조)

```
앱 (Chrome)                          승인 서버 (server/)               토스페이먼츠
──────────────                       ─────────────────               ──────────────
[결제하기] 누름
  ├ 입력 내용을 브라우저 저장소에 보관
  └ 토스 결제창 열기 ──────────────────────────────────────────────▶ 결제창 (카드 입력)
                                                                        │
앱으로 돌아옴 ◀─────────────────── ?payment=success&paymentKey=…&orderId=…&amount=… ┘
  ├ 보관해둔 입력 내용 꺼내기
  ├ 금액 맞는지 확인
  └ POST /confirm ──────────────▶ 시크릿 키로 승인 요청 ─────────▶ /v1/payments/confirm
                                     ◀────────────────────────────── 승인 완료
  ◀──────────────────────────── {ok:true, payment:{…}}
  └ 예약 저장 → 완료 화면
```

**왜 서버가 필요해요?**
결제를 최종 확정(승인)하려면 **시크릿 키**가 필요한데, 앱(브라우저) 안에 넣으면 누구나 꺼내 볼 수 있어요.
그래서 시크릿 키는 `server/` 에만 두고, 앱은 서버에 "이 결제 승인해줘" 하고 부탁만 해요.

## 4. 파일 설명

| 파일 | 하는 일 |
|---|---|
| `lib/config/payment_config.dart` | **키·서버 주소 설정** (클라이언트 키, 승인 서버 주소, 모의 결제 켜기) |
| `lib/payment/payment_gateway.dart` | 결제 통로 — 앱은 이것만 불러요 |
| `lib/payment/payment_gateway_web.dart` | 웹(Chrome)용 — 토스 결제창 띄우기, 돌아온 결과 읽기 |
| `lib/payment/payment_gateway_stub.dart` | 웹이 아닐 때(테스트) — 모의 결제 |
| `lib/payment/pending_reservation.dart` | 결제창 갔다 오는 동안 입력 내용 보관 |
| `lib/payment/payment_confirm_api.dart` | 승인 서버에 요청 보내기 |
| `lib/screens/payment/payment_result_screen.dart` | 결제 후 돌아왔을 때 화면 (승인 → 저장 → 완료) |
| `web/index.html` | 토스 SDK `<script>` 한 줄 |
| `server/confirm_server.js` | 승인 서버 (외부 라이브러리 없음, `node` 만 있으면 됨) |

## 5. 실제 결제로 바꾸기 (나중에)

1. https://developers.tosspayments.com 가입 → **사업자등록증**으로 계약 심사 → 운영 키 발급
2. `lib/config/payment_config.dart` 의 `kTossClientKey` → `live_ck_…` 로 바꾸기
3. 승인 서버를 인터넷에 올리기 (Firebase Functions, Render, Railway 등 아무거나) 하고
   시크릿 키는 **환경변수**로: `TOSS_SECRET_KEY=live_sk_… npm start`
   ※ 코드나 GitHub에 시크릿 키를 절대 적지 마세요.
4. `kPaymentServerUrl` 을 올린 서버 주소로 바꾸기 (`https://…`, 끝에 `/` 없이)
5. 예약을 진짜 DB(Firebase 등)에 저장하려면 `server/confirm_server.js` 의
   `// 여기서 나중에 Firebase 등 진짜 DB에 예약을 저장하면 돼요.` 자리에 넣으면 돼요.

## 6. 자주 바꾸는 것

- **예약금 금액** → `lib/screens/reservation/reservation_models.dart` 의 `kDepositPerPerson`
  (서버 `server/confirm_server.js` 의 `DEPOSIT_PER_PERSON` 도 같이 바꿔요 — 금액 검사용)
- **결제창 없이 화면만 시연** → `payment_config.dart` 의 `kUseMockPayment = true`
- **내 테스트 키로 바꾸기** → 토스 개발자센터 → 내 개발정보 → 테스트 클라이언트 키 / 시크릿 키
